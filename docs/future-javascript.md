# Future JavaScript: Now
Майбутній JavaScript: Зараз

Однією з головних переваг TypeScript є те, що він дозволяє використовувати безліч функцій з ES6 і вище в сучасних (рівня ES3 і ES5) JavaScript-рушіях (таких як сучасні браузери і Node.js). Тут ми глибоко зануримося в те, чому ці можливості корисні, а потім покажемо, як вони реалізовані в TypeScript.

Зауваження: Не всі з цих можливостей заплановано для негайного додавання до JavaScript, але вони можуть бути дуже корисними для організації та підтримки вашого коду. Також зауважте, що ви вільні ігнорувати будь-які конструкції, які не мають сенсу для вашого проекту, хоча зрештою ви будете використовувати більшість з них ;)
